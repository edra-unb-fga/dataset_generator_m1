# PROTOTYPE: Configuration Cockpit

This throwaway prototype asks whether one terminal cockpit can make four connected states understandable:
profile selection, an ordered custom effect stack, preflight receipt invalidation, and run control.

Run it with:

```powershell
uv run python prototypes/config_cockpit/app.py
```

The state model is intentionally portable. The terminal shell is a primary-source experiment and must
not be merged into production.
