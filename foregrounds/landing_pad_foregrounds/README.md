# Independent geometric workflow fixtures

These images are generated from the repository-authored `scripts/generate_pad_fixtures.py` using
rectangles, a circle and a cross. No uploaded image bytes are copied. They are synthetic test/starter
assets, not verified production artwork or real photographs. The original uploaded JPEG is not
available in this checkout. Before publishing that original artwork, obtain its source and
redistribution permission. Use your production images through a composer foreground-root override.

Both the 512×512 square and 640×400 rectangle label the complete opaque panel as class `pad`.
