# Dataset Generator M1 Agent Router

Start with the smallest source that matches the task:

- Domain language and invariants: `CONTEXT.md`
- Executable product contract: `docs/SPEC.md`
- Code, tests, worktrees, and pull requests: `docs/DEVELOPMENT.md`
- Controlled studies and performance evidence: `docs/EXPERIMENTS.md`
- Future work and explicit deferrals: `docs/ROADMAP.md`

Keep foreground and background geometry on the same homography. Preserve foreground alpha through
appearance-only effects. Do not tune performance from a single machine or mix experimental outputs
with tracked source. Use a worktree for throwaway prototypes and concurrent feature work.
