# Coherent scene candidate

Opt-in, uncalibrated combination of alpha-correct foreground resampling, a bounded
background-guided colour shift and one scene-wide illumination field. Geometry uses
the standard scene settings. This stronger candidate responds more often and permits
larger shifts than the restrained context study, while its brightness and chroma caps
are much smaller than the broad treatment that produced purple and washed-out targets.
The bounds are engineering choices, not a visual qualification or physical lighting.
They cannot produce contact shadows or remove lighting baked into photographs. Review
each family and run paired comparisons before considering any default change.
