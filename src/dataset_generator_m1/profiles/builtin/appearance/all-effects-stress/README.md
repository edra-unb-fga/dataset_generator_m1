# All effects stress

Forces a broad cross-section of supported appearance effects to exercise validation, tracing, timing, alpha handling, and worst-case pipeline behavior. It includes both native `AtmosphericFog` and patch-based `RandomFog` because they are distinct effects.

This profile is benchmark-only, visually implausible as a general default, and requires an explicit warning receipt. Use smaller probes first. Its timings must be interpreted within one recorded environment; they are not cross-machine budgets.
