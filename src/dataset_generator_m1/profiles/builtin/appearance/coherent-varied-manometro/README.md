# Coherent varied manometro candidate

Experimental profile for review. Reduces motion blur frequency and limits its kernel to three pixels to protect small dial markings. Not a promoted default.

A matched 640-pixel replay of manometro slot 16 (seed 20261106) associated the original 5-pixel motion blur with visibly softened dial markings; the same scene with this profile did not activate blur and retained finer detail. This one case supports testing reduced blur, not a calibrated frequency or detector-quality claim.
