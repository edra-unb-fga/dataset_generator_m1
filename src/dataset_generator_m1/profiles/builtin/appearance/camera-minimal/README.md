# Camera minimal

Experimental restrained final-image lighting, exposure, short motion blur and JPEG variation.
All effects operate after composition, so foreground and ground receive the same camera treatment.
No independent foreground recolouring or background hue replacement is applied.

Select with `appearance: {preset: builtin:appearance/camera-minimal}`. This is a candidate for
comparison, not a calibrated sensor model, a physical lighting model or a new default. It does not
add contact shadows or establish detector accuracy. Compare at the intended output size and source mix.
Evidence and limitations: `docs/experiments/profile-tradeoffs-v1/README.md`.
