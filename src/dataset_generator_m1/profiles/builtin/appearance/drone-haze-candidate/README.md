# drone-haze-candidate

Light synthetic directional haze. Synthetic depth is an approximation, not measured scene depth.

Experimental opt-in. Geometry, alpha and annotation policy are unchanged. All lighting/camera changes
operate on the composed scene. Physical scale and camera calibration are unknown. Compare with
current-fast and realistic-heavy using forced fixtures and natural activation rates. A visual review
does not prove detector accuracy. No existing default or heavy effect is removed.
